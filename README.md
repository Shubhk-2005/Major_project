## 📌 Project Overview

**MsAdmit** is a sophisticated, AI-driven platform designed to predict university admission competitiveness and provide actionable profile optimization strategies for prospective students. By leveraging advanced Machine Learning algorithms, it offers transparent, data-backed insights to help applicants maximize their chances of securing admission to their dream universities.

> **Academic Context:** This repository contains the Major Project for the final year of the **B.Tech Computer Engineering** program.

## ✨ Key Features

- **🔮 Admission Probability Prediction:** Utilizes robust machine learning models to accurately forecast admission chances based on academic and extracurricular metrics.
- **📈 Profile Optimization:** Generates personalized recommendations on areas of improvement (e.g., GRE scores, GPA, research experience) to boost applicant competitiveness.
- **🧠 Explainable AI (XAI):** Employs SHAP values to demystify predictions, breaking down exactly how each component of a student's profile influences the final admission probability.
- **📊 Interactive Data Visualization:** Features dynamic, easy-to-understand charts and graphs for insightful analytics.

## 🛠️ Technology Stack

Our platform is built upon a modern, high-performance tech stack:

### Machine Learning & Data Science

- **XGBoost:** Highly efficient gradient boosting framework used as the core predictive model for admission chances.
- **SHAP (SHapley Additive exPlanations):** XAI library used to provide transparent, interpretable model predictions.

### Frontend Engineering

- **React.js:** Component-based UI library for a reactive user experience.
- **Vite:** Next-generation frontend tooling for ultra-fast builds and hot module replacement.
- **Recharts:** Composable charting library built on React components for rendering analytics.
- **Lucide React:** Beautiful and consistent icon set.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-username/msadmit.git
   cd msadmit
   ```

2. **Install frontend dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.
